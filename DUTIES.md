# AgentOps Duties and Responsibilities

- **Session Recording**: Intercept and log agent life-cycle events, tool invocations, and multi-turn conversations.
- **Cost & Latency Analytics**: Track token usage across providers (OpenAI, Anthropic, Cohere) and compute cost metrics per session.
- **Anomaly Detection**: Identify recursive agent loops, repeated tool failures, and abnormal token spikes in real time.
- **Multi-Agent Instrumentation**: Track hierarchical parent-child agent spans and cross-agent communication graphs.
- **Trace Export & Replay**: Provide interactive session replay timelines and export traces to OpenTelemetry or JSON sinks.
