# LLM Cost and Latency Monitoring Skill

Profiles resource consumption across foundation model interactions.

## Core Capabilities
- Maps token consumption to standardized pricing tables across providers.
- Computes p50, p95, and p99 latency percentiles across session steps.
- Enforces token budget ceilings to prevent cost runaway.
