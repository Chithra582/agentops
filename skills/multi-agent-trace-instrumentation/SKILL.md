# Multi-Agent Trace Instrumentation Skill

Instruments distributed, multi-agent frameworks with unified telemetry.

## Core Capabilities
- Propagates distributed trace contexts across agent communication channels.
- Correlates sub-agent actions back to root user sessions.
- Exports traces to standard OpenTelemetry collectors and visual dashboards.
